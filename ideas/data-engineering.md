# Data Engineering — Task Ideas

> Data engineering tasks often require instinct, taste, and careful data inspection.
> They can be arbitrarily hard for agents but are often hard to programmatically verify.

## Ideas

### Fuzzy Dedup on Noisy Dataset
- **Difficulty:** expert
- **Source:** community (TB 3.0 Discord)
- **Description:** Agent must deduplicate a massive, noisy dataset using various techniques (MinHash, SimHash, edit distance, etc.)
- **Why it's hard:** Requires choosing the right dedup strategy based on data characteristics, handling edge cases, and optimizing for scale
- **Key skills tested:** data profiling, algorithm selection, performance optimization
- **Status:** idea

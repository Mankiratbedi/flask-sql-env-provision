# Distributed Systems — Task Ideas

> Distributed engineering is very hard and can produce good candidates, but with system
> constraints, many components must be simulated. The simulation will inevitably make
> many aspects easier for agents, so extra precaution is needed when designing the task.

## Ideas

### Distributed Top-K
- **Difficulty:** expert
- **Source:** community (TB 3.0 Discord)
- **Description:** Agent must evaluate tradeoffs between different algorithms and implement an efficient distributed Top-K algorithm that runs across different nodes in parallel
- **Why it's hard:** Requires understanding distributed algorithm tradeoffs, network costs, and parallel execution
- **Key skills tested:** distributed algorithms, performance analysis, parallel computing
- **Status:** idea
